# ПарГид — прототип сервиса бань и саун

Кликабельный мобильный web-прототип сервиса поиска бань и саун в Калининграде.

## Что уже работает

- интерактивная карта Калининграда на Leaflet + OpenStreetMap;
- демо-маркеры бань и саун;
- поиск и фильтры;
- карточка заведения с фото, ценой, услугами и рейтингом;
- избранное через localStorage;
- кнопки «Позвонить», «Построить маршрут» и демонстрация интеграции Yandex Go;
- сценарий «Запросить бронь» с датой, временем, длительностью и количеством гостей;
- сохранение заявок в браузере;
- раздел «Мои заявки»;
- адаптивный интерфейс под мобильный экран.

## Запуск

Прототип полностью статический: достаточно открыть `index.html` в браузере.

Для локального запуска:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## GitHub Pages

В репозитории откройте **Settings → Pages** и выберите публикацию из ветки **main**, папка **/(root)**.

После включения Pages сайт должен быть доступен по адресу:

`https://yumis84.github.io/sauna-map-prototype/`

> Все названия, адреса, цены, телефоны, рейтинги и описания заведений в текущем прототипе демонстрационные. Перед коммерческим запуском нужна собственная/лицензированная база данных заведений и реальные интеграции backend, Telegram, push-уведомлений и бронирований.
