# ПарГид — бани и сауны Калининграда

Мобильный web-сервис поиска бань и саун на карте Калининграда.

> **Статус:** текущая рабочая версия зафиксирована как финальная на 16.08.2026. Дальнейшие изменения — только в рамках новой согласованной итерации.

## Что работает

- интерактивная карта Leaflet + OpenStreetMap;
- актуализированный каталог бань и саун;
- поиск и фильтры на карте и в каталоге;
- нижняя карусель карточек, синхронизированная с картой;
- выделение активной метки при листании карточек;
- геолокация пользователя «Вы здесь»;
- карточки заведений с фото, ценами, услугами и рейтингом;
- свайп вниз для закрытия карточки;
- свайп влево/вправо между заведениями с синхронизацией списка на фоне;
- избранное с SVG-сердечками и синхронизацией состояния;
- фотогалереи и источники фотографий;
- кнопки звонка и построения маршрута;
- встроенный AI-чат через n8n;
- защита карты от некорректного восстановления после переходов между разделами.

## Активная UI-логика

Финальный интерфейс использует в том числе `swipe-fix-v6.js`, `venue-swipe-v9.js`, `favorites-v12.js`, `favorites-map-keepalive-v14.js`, `map-return-fix-v13.js`, `user-location-v16.js`, `catalog-search-v18.js`, `detail-actions-top-v19.js`, `rating-ui-v17.js`, `map-photos-v15.js`, `n8n-chat-v23.js` и связанные актуальные модули данных/источников.

Старые дубли `swipe-fix.js` и `map-card-sync.js`, функциональность которых уже входит в актуальные модули, удалены.

## Запуск

Прототип полностью статический на frontend-стороне: достаточно открыть `index.html` через локальный HTTP-сервер.

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.
